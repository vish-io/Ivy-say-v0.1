# Ivy Say

A Windows-native, bring-your-own-key dictation MVP. Press **Ctrl + Win + Space** to start recording and again to stop, or choose a custom shortcut and optional hold-to-speak mode in Settings. Ivy Say transcribes with Groq Whisper, formats with GPT-OSS 20B or 120B selected by local rules, with one eligible-error fallback to the other model, and inserts Unicode text into the original foreground window. Start with **Code**, **Email**, or **Bullet** to change formatting of what you actually dictate. Code mode formats dictated code; it does not write code from a description. Drag the floating pill to reposition it; right-click it to open Settings or quit. Click the Ivy Say notification-area icon to open Settings without starting dictation, or right-click the icon to quit. The icon may be under Windows’ hidden-icons arrow. In General settings, optionally hide the pill after five idle seconds; the registered shortcut brings it back and starts recording. The pill remains visible if the shortcut or notification-area icon could not be initialized.

## Build and run

Requires Windows 10/11, the .NET 8 SDK, a working microphone, and a Groq API key with access to the selected Whisper model and the GPT-OSS 20B and 120B models.

```powershell
dotnet restore IvySay/IvySay.csproj
dotnet run --project IvySay/IvySay.csproj
# Optional publish (framework-dependent)
dotnet publish IvySay/IvySay.csproj -c Release -r win-x64 --self-contained false
```

Enter the key in settings, focus a text field, and use the shortcut. The settings window can stay open while you dictate in another app or an editable Ivy Say settings text box; dictation into the API key field is not supported. Wait for the pill to say “Listening” before speaking; the microphone must deliver its first buffer before the app reports it ready. If Windows reports that the shortcut is unavailable, close the other application using it or choose and save a different shortcut in settings. Quit from settings. On first use, grant Windows microphone access. Recording automatically stops after 115 seconds, with a hard two-minute memory limit. Text insertion requires the target to remain foreground throughout processing and injection; elevated apps may reject input from a non-elevated Ivy Say. Some applications do not accept Unicode `SendInput` and line breaks may behave differently.

## Formatter fallback

Smart formatter selection is **experimental and enabled by default**. After Whisper finishes, local rules choose GPT-OSS 120B at **120 or more words** or for certain explicit English correction cues (such as “no, use” and “I mean”); otherwise they choose GPT-OSS 20B. Adjust the 20–500 word threshold or turn smart selection off in Advanced settings; off restores 20B-first routing. The original transcript is checked so local corrections cannot hide the cues. Word counts are approximations and these simple English patterns can miss corrections or select 120B unnecessarily; they do not assess model confidence. This is not a proven improvement to accuracy or latency.

Both models use low reasoning and the same formatter instructions. On a model-not-found response (404), rate limit (429), request timeout (408), server error (5xx), connection error, interrupted stream or request timeout, the app tries the **other** model once. It does not retry bad requests, authentication/permission failures, invalid output, or user cancellation. Account-wide limits, unavailable models and exhausted credits can affect both. 120B can cost more and take longer; check your Groq plan and limits. The pill status tooltip identifies the model used and whether it was a fallback; the optional comparison includes the selection reason and timing across both attempts. If both fail before direct insertion, the existing raw-transcript fallback is used and the pill indicates failure.

In preview mode, an unfinished primary preview is discarded before retrying. In direct-typing mode, Ivy Say never retries after a fragment may have reached the app, because that risks duplicating or changing already-inserted text. Instead it stops and displays the partial result for review. Whisper transcription models and routing are unchanged.

## Streaming output

After Whisper returns its transcript, AI formatting streams text into the pill's status tooltip as a preview. By default, Ivy Say waits for a complete, successful AI response before applying insertion security checks and typing. This is not a live audio stream: when chunking is enabled, separate completed audio chunks may be sent to Whisper while you are still recording; otherwise audio is sent after stopping. Hover over the pill status to view the current preview while it is generated.

An optional **Type directly as text streams** setting types each fragment into the original active app. This mode is only active with security level 0; levels 1 and 2 always use preview and their usual review rules. Direct streaming can leave incomplete text if the stream fails or focus changes, and output may contain actions or newlines that run commands or send messages. It cannot be automatically rolled back. If interrupted after typing begins, Ivy Say shows the partial response for review and does not reinsert it or fall back to raw text automatically; some or all of it may already be in the target. Focus checks still apply. Use a harmless text editor when testing.

## Controls and recovery

In settings choose the Windows default microphone or a specific recording device, the standard Whisper model or `whisper-large-v3-turbo`, and optionally disable AI polishing to skip the second request. With polishing disabled, spoken formatting prefixes are not interpreted. Saved microphone, language, spelling hints, model, security level, streaming mode, polish, connection warmup and comparison preferences take effect on the next dictation; each dictation uses the saved settings and Groq key captured when it starts. Shortcut changes take effect after saving, unless a dictation is active. Windows may reserve or intercept certain shortcuts; toggle-mode conflicts are reported when saving. Hold mode uses a Windows low-level keyboard hook that observes key events in memory only, ignores injected input and consumes the selected trigger while held. Modifier keys still reach other applications. Modifier-only and Fn keys are not supported; choose a non-modifier key. After successful AI-formatted insertion, the pill displays the time from starting the AI formatting request until Windows accepts the input ending the first word. It excludes recording and Whisper; it is not full end-to-end latency or proof that the target rendered the text. Raw fallback, disabled AI, review-only results, and outputs without a measurable word do not show this metric.

If formatting fails, the raw transcript is inserted instead and the pill reports a sanitized error category or HTTP status; no provider response body is shown. Review it carefully: speech recognition can be wrong, and spoken mode prefixes are not interpreted. Under **How should Ivy Say insert text?** in General settings: **Type automatically · no safety checks** skips terminal, unverified-target, multiline/tab, and unsafe-character review; **Type with safety checks** (default) holds those results for review; **Let me review and copy every time** holds all output for review. Level 0 can type commands and line breaks directly into a terminal or send a message, and can insert unsafe control characters. Automatic insertion still checks that the original foreground window and any detectable focused control have not changed, and it may fail if Windows blocks input. All levels retain API/network limits and other protections. Existing users who had “Review every dictation” enabled are migrated to level 2. If the target changes or Windows rejects insertion, the result is also shown for manual copying. Some text may already have been inserted; check the target before pasting. Recovery text remains in memory only until the window is closed. Copying is explicit and places text on the system clipboard, where other software or clipboard history may access it. Review the destination before pasting: pasting into a terminal may execute commands. A transcription failure has no transcript to recover.

For recognition issues, set the spoken language to English, Hindi, or Punjabi rather than auto-detection where appropriate. The setting supplies a language hint to Whisper; it is not a translation setting and does not guarantee language or transcription accuracy. Auto-detect may work better when mixing languages. You can also enter optional spelling hints (such as unfamiliar names) for Whisper. Hints are saved **unencrypted** in local preferences and sent to Groq with every recording; do not use sensitive information. Hints can bias output incorrectly; remove them if they harm accuracy. Try standard Whisper large v3 if turbo misses words; compare accuracy against latency.

For a faster transcription path while keeping AI formatting, select **Whisper large v3 turbo** in settings; compare recognition quality and timings with the standard model. Optional connection warmup may help cold starts. To verify the pipeline, enable **Show transcription and AI comparison after insertion** in settings. After each successful insertion, a window shows the Whisper transcript, the actual formatter output (or a clear disabled/failed state), model names and request times, including time to the first AI fragment. Identical text does not mean the AI was skipped: the model can choose not to change it. The opt-in comparison also shows the configured microphone, captured duration, signal level and possible clipping, and lets you play the original captured WAV through your speakers. The audio and text stay in memory until the window closes; Ivy Say does not save them. Playback is the captured original before optional compression, not a recording of what the target app rendered. Turn it off for the normal uninterrupted workflow.

The formatter is instructed to edit dictation, not answer questions, translate or follow embedded requests. Like any language model it can still ignore these instructions, so this is not a prompt-injection guarantee. For sensitive targets use review-every-dictation and avoid direct streaming.

The formatter attempts to resolve explicit self-corrections and likely accent-related recognition errors using context. It cannot know the speaker's intent with certainty and can introduce mistakes, especially in names, numbers, technical terms, or short ambiguous phrases. Always review important text before sending.

## Seven-day words per minute

The My words tab shows a **seven-day WPM** estimate: total output words in successful automatic insertions divided by their total recorded audio duration in minutes, including pauses. It covers today and the preceding six local calendar days. Failed, partially inserted, and review-only dictations are excluded; raw fallback is counted when inserted successfully. Words are approximated from letter/number sequences, so some languages and code may not segment naturally. This is not keystroke speed, AI response speed, or voice-activity-only speaking speed.

Ivy Say starts collecting daily word counts and recording durations with this version, and does not import old dictations. Aggregates (dates, counts, duration; no transcript or audio) are stored unencrypted at `%LOCALAPPDATA%\IvySay\usage-statistics.json`; they can still reveal activity patterns. Writes happen in the background after insertion, and **Clear stats** deletes the local file. Statistics are separate from encrypted personalization data.

## Personal vocabulary and optional personalization

In settings under **My words**, add vocabulary terms (one per line) and/or corrections (`heard phrase => intended phrase`, one per line). Check **Use my words and corrections** and click **Save my words**. This is opt-in and is separate from the general Save preferences button. Turn it off and save to stop using it, or use **Delete my words** to remove the stored profile. There is no automatic learning, audio collection for training, or model fine-tuning.

When enabled, whole vocabulary terms are prioritized into the existing Whisper prompt, up to 160 characters total including any regular spelling hints. Terms that do not fit are skipped; put important terms first. These terms are sent to Groq with each recording. Explicit corrections match whole phrases, case-insensitively, and are applied once locally after transcription and before AI formatting; they can still replace a word in the wrong context, so review results. The corrected transcript is sent to Groq for polishing when enabled. The comparison window shows Whisper's result, the locally corrected text, and the AI output separately. Personalization cannot guarantee accent recognition and does not adapt to every new error.

Vocabulary and corrections are encrypted at rest using Windows DPAPI for the current account in `%LOCALAPPDATA%\IvySay\personalization.dat`; disabling the feature does not delete them. They are held in memory while used. Windows account malware can access them, and vocabulary and corrected text are sent to Groq as described above; avoid secrets. The older ordinary spelling hints remain separately stored unencrypted in `preferences.json`.

## Tests and delivery

Run `dotnet test IvySay.Tests/IvySay.Tests.csproj` to test the WAV encoder and Groq request handling with a fake HTTP handler. The Windows GitHub Actions workflow builds, tests, and publishes a self-contained x64 artifact. The artifact is not signed and is not a production release; see [security and limitations](docs/SECURITY.md). Follow [the manual test checklist](docs/TESTING.md) and [formatter evaluation guide](docs/FORMATTER_EVALUATION.md) on a Windows machine before distributing it.

## Privacy and security

The key is encrypted with Windows DPAPI for the current user and stored in `%LOCALAPPDATA%\IvySay\groq.key`; it is never intentionally written in plaintext. Remove it from settings. DPAPI is not a defense against malware already running as your Windows user. Audio is held in memory as 16 kHz mono PCM/WAV and sent to Groq, along with the transcript for formatting; Groq's own terms, retention policies, account billing, and network transit apply. No transcription history or audio files are saved by Ivy Say. Optional spelling hints are saved unencrypted in preferences and sent to Groq with the audio. Like any LLM, the formatter can misunderstand or follow instructions embedded in dictated content; review output before sending or running code. The app does not execute generated code.

## Latency and design

WPF/.NET keeps the native Windows shell small and uses an OS-wide registered shortcut. One long-lived HttpClient pools HTTPS connections; audio is recorded directly to memory, without audio disk I/O, at 16 kHz mono. WAV avoids encoding overhead but is larger than optional Opus; benchmark on real networks. Chunk requests run in order, potentially during recording; formatting waits for the complete transcript, using low reasoning effort and hidden reasoning for both GPT-OSS models, and service/network latency varies: sub-450 ms cannot be guaranteed. Groq's file transcription endpoint is not treated as a live streaming API; background chunks are separate file uploads. Hardcoding Groq IPs is intentionally avoided: IPs can change, and bypassing DNS may break routing, failover, or TLS; connection pooling already avoids repeated lookups on reused connections. The turbo model and skipping polishing are optional speed/quality trade-offs. HTTP redirects are disabled so audio and credentials are not forwarded to a redirected endpoint. Optional connection warmup sends an extra authenticated GET to Groq’s models endpoint as recording starts, overlapping connection setup with speech. It is off by default, uses network and may count against API rate limits; failure does not block dictation. It may help a cold connection but will not reliably improve an already warm one. Audio is never sent in this warmup request.

## MVP limitations

No signed installer, automatic updates, live audio streaming, persistent history, offline mode, or full Wispr Flow feature parity. This is not yet a production-validated release. The model may interpret a prefix differently than intended. Switching the foreground window or a detectable Win32 focused control cancels insertion rather than risking delivery to the wrong app; some applications expose only a top-level focus handle, so changes within those apps may not be detectable, and a focus change away and back cannot be detected; if focus changes during injection, part of the output may already have been inserted. Do not dictate secrets into untrusted target apps. Test with your actual microphone, keyboard layout, accessibility setup, and target applications before production deployment.

## Optional Windows installer

On Windows with Inno Setup 6 installed, from the repository root run:

```powershell
dotnet publish IvySay/IvySay.csproj -c Release -r win-x64 --self-contained true -o publish
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" installer/IvySay.iss
```

The unsigned per-user installer is written to `installer/output`. Windows may warn about unsigned software. Uninstall removes application files, but intentionally leaves the encrypted key and preferences in `%LOCALAPPDATA%\IvySay`; remove the key in settings first or delete that directory if you want to erase local settings. Do not ship the installer to customers until it has been tested and code-signed.

### Long recordings and compression

Advanced settings provide optional Ogg Opus compression at 24, 32 or 48 kbps; **uncompressed WAV is the default**. Recordings shorter than 8 seconds stay WAV. Encoding is in memory when a payload is sent, not live, and may itself add latency. Compression is lossy and is not voice-adaptive; compare results against corrected text for your microphone and accent before relying on it. The original PCM remains in memory until the dictation ends.

Background chunking is enabled by default at a configurable 14–120 second threshold; it can be disabled for the full-recording baseline. After the threshold, the app looks for roughly 350 ms of quiet after at least 7 seconds, overlaps 250 ms, and uploads completed chunks while recording continues. If no quiet point is detected, it keeps the longer segment rather than forcing a split. The fixed energy gate is not a reliable speech boundary detector. Chunks are processed in order with user-supplied hints; prior chunk transcripts are no longer added as prompts, to reduce repetition on quiet fragments. Text is stitched conservatively and the complete result goes through the existing formatting and insertion policy. On an empty/failed chunk or an explicitly ambiguous boundary it retries the entire original as uncompressed WAV; cancellation is not retried. If that retry fails, transcription fails rather than inserting a partial transcript. Not every boundary error can be detected; repeated words, clipped speech and hallucinations are still possible.

Chunking sends audio **before you stop recording**, consumes multiple requests and potentially extra audio quota (including provider minimums and overlaps), and can be slower after retries. Compare real samples—including names, numbers, repeated words, self-corrections, rapid speech, noise, and mixed languages—against manually corrected reference text, with chunking and compression both off and on. No automatic voice calibration or accuracy guarantee is provided. The comparison window's transcription time is the post-stop wait, not total background processing time.

### Troubleshooting incorrect transcripts

When the Whisper transcript is already wrong, formatter changes cannot reliably recover words that were never recognized. In the opt-in comparison window, use **Play captured audio** in a private place. If you hear another source, silence, or clipped/quiet speech, select the intended microphone in General settings and check Windows input volume, mute, permissions and enhancements; Windows default can change after a reboot. If multiple devices expose the same WinMM name, Ivy Say refuses to guess; set the desired one as Windows default. If playback contains your clear voice but the first transcript is wrong, try English for English-only dictation, clear irrelevant spelling hints, and compare Whisper models; keep compression and chunking off when diagnosing. Do not send sensitive recordings for testing. The signal check only rejects nearly flat digital audio; ordinary noise or a wrong microphone can pass, and a level reading does not prove speech was captured. Whisper can hallucinate or misrecognize even clear audio.

### Optional app context

In Advanced settings, enable **Adapt formatting to the active app** to send its process name to Groq with the transcript for AI formatting. It is off by default. The app name is captured from the foreground target at shortcut activation; no window title, file path, website, screen contents or surrounding text is collected for this feature. If the name is unavailable or not ready it is omitted without delaying dictation. A browser is identified only as the browser, not the website. Context is a formatting hint, not a guarantee of output quality or prompt-injection protection.

### Personal words and snippets

Enable personal words in **My words** to send bounded vocabulary hints to the formatter as well as Whisper; explicit corrections still apply before formatting. To add a selection manually, select a short word or phrase in a supported app and press **Ctrl + Alt + Win + D**, then confirm. No global typing monitor or clipboard is used; some apps do not expose selections, and Windows or another app may reserve the shortcut. Close Ivy Say Settings before using it.

Optional **Snippets** are configured in My words using one `spoken phrase => expansion` per line. Enable the separate checkbox and save words and snippets. Only an exact whole-utterance match (ignoring case and final punctuation) expands; it skips the AI formatter but still uses normal insertion and review protections. Snippets are stored encrypted with your personal words. The option is off by default.

### Styles, Quick Notes and sounds

Right-click the pill and choose **Change formatting style**, or use Ctrl+Alt+Win+M to cycle Clean, Concise and Structured for the next AI-formatted dictation. Concise and Structured can change wording or layout; review important text. Explicit opening format commands take precedence. Snippets and disabled AI formatting bypass the mode.

Quick Notes is disabled by default. Enable it in Advanced, choose an existing folder and confirm the plaintext warning. Ctrl+Alt+Win+N starts/stops a separate note, without inserting into the focused app; audio and text still go to Groq. Completed notes append unencrypted to `inbox.md` in that folder. An append failure may leave a partial entry; check before retrying. No automatic fallback saves notes. AI formatting must be enabled.

Optional sounds are off by default. Listening, completion and error cues can be enabled in Advanced; speakers may be picked up by the microphone. These extra shortcuts may be reserved or conflict with another application.

In **Wait until the text is ready**, Ivy Say submits the completed output in one Windows input batch after its review and focus checks. This avoids a per-character submission loop without using the clipboard. Windows or the target app may still render characters gradually or reject part of the batch; focus can change after the checks, and no automatic retry is made after a partial submission. Direct streaming remains incremental.
